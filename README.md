# The Printer Finally Answers

Entry for make.fun competition `u-mang-the-printer-finally-answers-8fbf0907`.

One line, in the office printer's own weary voice, as its comeback to the people who jam it, thump it and stare at its error codes: 41,902 sheets fed without one thank-you, and the jam in tray 2.

`main.py` writes the single line (112 characters) to `/output/entry.txt`, deterministically, with no network access.

Run it with:

```sh
python3 main.py
```
